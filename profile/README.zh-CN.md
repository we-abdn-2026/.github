## 🚀 支线任务，随时出发

- 🎮 做个东西给朋友玩。看着他们玩出你没想到的 Bug。记下来，下次修。
- 🛠️ 想要的小工具没人做？自己来，顺便给后来的人留一份。
- 🔬 好奇它怎么工作？跑一下，拆开看看。
- 🌱 课上没教过？正好学点新的。从「这要怎么开始」问起也行。

小游戏、实用脚本，或者暂时没什么用的实验。**想做，因为好玩。这个理由就够了。**

## 🐛 非常合理的开发流程

```text
💡「要不我们……」
 └─ 🧑‍💻「这个应该不难。」
     └─ 🐛「等一下，怎么回事？」
         └─ 🔍「哦，我写的。」
             └─ 🎉「跑通了！快来看！」
```

跑通的那一刻，有人一起看到，会更开心。

## 🤝 一个人能做，一群人更好玩

有个还没成形的点子、一张草图，或者一个没想明白的问题，都可以带过来。挑个感兴趣的仓库，开个 Issue 聊聊，不用等想清楚了才加入。

**吐槽 Bug，别攻击写 Bug 的人。** 也别忘了：**不是每个项目都得有商业模式。**
