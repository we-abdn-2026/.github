# 🧪 we-abdn-2026

### 非官方「如果……会怎样？」系

我们是来自[阿伯丁大学](https://www.abdn.ac.uk/)的计算机科学专业学生。

我们对一切都充满好奇，也享受把想法变成现实的过程。

[📂 看看我们最近在做什么](https://github.com/orgs/we-abdn-2026/repositories)

## 🚀 欢迎开启支线任务

- 🎮 做个朋友能亲手试玩的东西。看着他们马上以意想不到的方式使用它，然后认真记下来。
- 🛠️ 做出那个你一直希望有人开发的小工具，并把它留在后来的人能够找到的地方。
- 🔬 把「我想知道它是怎么运作的」变成一个可以动手试、跑起来或拆开研究的东西。
- 🌱 尝试课程之外的新事物——哪怕第一步只是弄清楚该从哪里开始。

一个小游戏、一段实用脚本，或一个暂时看不出用途的实验——**「因为做起来会很有趣」本身就是充分的理由。**

## 🐛 一个完全合理的开发流程

```text
💡「要不我们……」
 └─ 🧑‍💻「这应该很简单。」
     └─ 🐛「这个现象挺有意思。」
         └─ 🔍「哦，原来是我们的问题。」
             └─ 🎉「成功了！快来看！」
```

最后这一步，正是我们聚在这里的原因。做出来的东西能被别人看到，快乐也会加倍。

## 🤝 多人协作，乐趣加倍

带上一个还很粗糙的想法、一张草图，或者一个尚未想明白的问题。找到让你感兴趣的仓库，开一个 Issue 吧。你不需要先准备好完整的解决方案，随时都可以加入。

我们的原则是：**吐槽 Bug，不针对写 Bug 的人**；同时也别忘了，**不是每个项目都非得有商业模式。**

💡 有一个「如果……会怎样？」的想法？那就一起动手看看会发生什么吧。
